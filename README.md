## 想像一下

你在錄短影片。台詞記不住,提詞 app 又是一個大視窗擋在那邊。

你按 `Ctrl+Shift+Space`,打兩行台詞,按 Enter。台詞就浮在鏡頭旁邊——完全去背,只有字。
拖到順眼的位置,拉大,加個黑底。錄完按 Del,字消失,像沒存在過。

中途要看分鏡?`Win+Shift+S` 截個圖、`Ctrl+Shift+V`,圖直接上牆。

整個過程,螢幕上沒有出現過任何一個「視窗」。

---

## 怎麼開始

**最快:點兩下就能用** — 到 [Releases](https://github.com/Jeffrey0117/lanpai-overlay/releases/latest) 下載安裝版或免安裝版(Windows x64,不用裝 Node.js)。

或用原始碼跑:

```
git clone https://github.com/Jeffrey0117/lanpai-overlay.git
cd lanpai-overlay
npm install
npm start
```

開起來之後**螢幕上什麼都不會出現——這是正常的**。
看一下工作列右下角,有一顆藍色小圓點,它就在那裡待命。

## 怎麼用

### 兩顆快捷鍵就會了

| 按鍵 | 做什麼 |
|---|---|
| `Ctrl+Shift+Space` | 冒出輸入框:打字就是文字,貼圖片網址就是圖片 |
| `Ctrl+Shift+V` | 把剪貼簿裡的圖直接釘上螢幕 |
| `Ctrl+Shift+X` | 一鍵清空全部 |
| `Ctrl+Shift+↑` / `Ctrl+Shift+↓` | 叫到最前面 / 退到背景(被其他視窗蓋住);聚焦中按 ↑ 會叫回全部 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 復原 / 取消復原(滑鼠要在牆上的東西附近) |

最爽的用法:`Win+Shift+S` 截圖 → `Ctrl+Shift+V` 上牆,兩秒搞定。

### 東西上螢幕之後

| 動作 | 效果 |
|---|---|
| 按住拖曳 | 移動位置 |
| 拉右下角的小方塊 | 變大變小 |
| **滾輪懸停在上面滾** | 變大變小(更順手) |
| 點一下 | 浮出樣式面板 |
| 雙擊文字 | 重新打字 |
| `Alt`+拖曳 | 拖出一個分身(板子也行,整板複製) |
| **右鍵** | 刪掉(手滑了就 `Ctrl+Z`) |
| 按 `Del` 或點面板上的垃圾桶 | 刪掉 |

滑鼠不在這些東西上面的時候,整層完全不存在——你點滑鼠、打字、做任何事都不會被擋到。

### 樣式面板

點一下文字,上面會浮出一排小工具:

- **7 種顏色**直接點
- **粗細**:細 → 粗 → 黑,點一下換一段
- **陰影**:無影 → 柔影 → 強影 → 描邊。影子顏色會自動配——黑字配白影、白字配黑影,永遠看得清楚
- **底色**:無底 → 跟文字同一排顏色慢慢跳(黑、白、黃…都在裡面)。底會比字大一圈,壓在花背景上也清楚
- **存模板**:調好的樣式存起來(T1、T2⋯),下次點一下就套用,重開也還在

點圖片的話,面板是一個網址框:貼新網址按 Enter,原地換圖,位置大小都不變。

### 聚焦:只看這幾個

選中一個東西,工具列會多一顆 **「✦ 聚焦」**:點下去,螢幕上只剩它,其他暫時藏起來。要同時聚焦好幾個,先 **`Shift`+點** 把它們多選起來(被選的有藍框),再按聚焦——標題、圖、板子隨意組合。

按 **`Ctrl+Shift+↑`** 把全部叫回來(`Esc` 也行)。適合錄影時只想露一句台詞、或是把一組單字卡單獨拉出來看。聚焦時空白處照樣穿透,你可以一邊釘著幾個、一邊用底下的軟體。

### 選取組:存起來,一鍵叫回

老是要聚焦同一組?`Shift`+多選好之後,工具列那排數字 **`Shift`+點 1~7** 就把這組存起來;之後**點那個數字**就把這組叫回來並聚焦。閒置時按 `Ctrl+Shift+Space`,輸入框下面也有同一排可以叫回。重開還在,組裡被刪的便籤會自動跳過。右鍵數字 = 清空。

### 第一次打開不知道按什麼?

第一次開會跳一張**歡迎卡**,把最重要的幾個快捷鍵列給你看,按「知道了」就不再跳。想再看:右鍵托盤藍點 →「使用說明 / 快捷鍵」。

### 便籤板:把筆記分組

輸入框打 `#今天要做` 開頭加個 `#`,就會生出一塊有標題的板子:

- 把散落的便籤**拖進板子**,自動排成一列清單;板裡上下拖可以重排,拖出去就變回自由便籤
- **拖標題列**,整組一起移動
- 點標題列左邊的 **▾ 摺疊**,整板收成一條標題;再點展開
- 雙擊標題改名;點板子浮出面板可以**換標題顏色**(顏色 = 你的分類)
- 滾輪懸停在某一條上 → 只調那條;懸停在標題列 → 整板一起縮放
- 選中板子按 `Del` → 整組刪掉

拿來當待辦清單、單字卡、靈感堆都行——字幕工具用著用著就變筆記牆了。

### 工作列小圓點

忘記快捷鍵的時候,右鍵藍色小圓點,選單上都有(也標了快捷鍵提醒)。
「清空全部」「結束」也在裡面。

## 一些刻意的設計

- **會記得**:關掉再開,牆上的東西都還在。要從零開始,`Ctrl+Shift+X` 一鍵清空。沒有檔案要管理——它就是記得而已。
- **後悔藥**:內容變更自動留最近 30 個版本。`Ctrl+Z` 一步步回退;誤清空、誤刪板都救得回來。翻更舊的,右鍵小圓點 →「還原較早版本」挑一版。
- **不佔位**:沒有主視窗、不佔工作列、平常完全隱形。
- **樣式也會記得**:模板和你最後用的樣式跟著留。
